# Changelog

All notable changes are recorded here. Release headings use exact Git tags so `package.sh <tag>` can prove the artifact version.

## [Unreleased]

### Added

- Shared Claude Code/Codex bootstrap core with explicit platform adapters and one canonical hook dispatcher.
- Typed Wiki, Decision, Failure, and Workstream graphs with HEAD-only routers, strict link resolution, BFS discoverability from `context/index.html`, deterministic history, and non-mutating consolidation proposals.
- Canonical context-root identity shared across linked Git worktrees.
- Bounded task capsules, content-hash receipts, restoration checks, and hidden hygiene/control-plane mechanics.
- Neutral private Firstmate root, allowlisted project registry, review inbox, and explicit safe migration.
- Codex semantic model roles: Sol lead, Terra balanced, Luna economy, plus truthful direct-surface fallback and explicit catalog refresh.
- Reproducible exact-tag packaging, archive safety checks, payload parity, checksums, and installer dry-run gates.

### Changed

- Imported `contarch-15d5dd0` as the preserved Claude-focused baseline, then adapted behavior through shared harness-neutral contracts.
- Replaced model-visible hygiene narration with concise task/result/scope/fact/decision/blocker capsules.
- Consolidated lifecycle scripts behind normalized Claude and Codex event schemas while retaining Git pre/post-commit hooks.

### Verification

- Added adversarial fixtures for malformed hook payloads, unsafe paths, graph cycles/orphans, stale receipts, worktree locator tampering, model-catalog pagination/conflicts, partial-write rollback, and release failures.
- Live harness probes remain a dated, explicit gate; see `docs/compatibility.md`.
